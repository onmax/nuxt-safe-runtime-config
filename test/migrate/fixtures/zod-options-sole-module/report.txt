Now required at startup. The codemod removed the '' placeholders of these keys, so the server exits with NUXT_E8014 unless their variables are set. To keep a key optional, make it optional in the schema:
  - nuxt.config.ts:16 runtimeConfig.githubWebhookSecret: set NUXT_GITHUB_WEBHOOK_SECRET
  - nuxt.config.ts:17 runtimeConfig.githubPrivateKey: set NUXT_GITHUB_PRIVATE_KEY

Nuxt does not check these schema rules. Check them in server code where they matter:
  - layers/runtime-config/nuxt.config.ts:5 githubWebhookSecret: minLength 1

Behaviour changes:
  - nuxt.config.ts:24 validateAtBuild: false is gone. Nuxt checks runtimeConfig during the build, and a missing value only warns (NUXT_B5032)
  - nuxt.config.ts:25 validateAtRuntime: false is gone. Nuxt always checks runtimeConfig when the server starts
  - nuxt.config.ts:26 onError: 'warn' is gone. Nuxt stops the server on an invalid value (NUXT_E8014) and has no warn mode
  - nuxt.config.ts:27 jsonSchemaTarget is gone. Nuxt always converts the schema to JSON Schema draft-2020-12
  - layers/runtime-config/nuxt.config.ts:8 maxTokens: z.coerce: Nuxt coerces NUXT_* values from the JSON Schema type instead
  - layers/runtime-config/nuxt.config.ts:9 retry: .catch(): Nuxt fails on an invalid value instead of using the fallback
