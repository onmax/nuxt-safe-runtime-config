## Options

Options go under `safeRuntimeConfig` in `nuxt.config.ts`. Set `$schema` or `envSchema`, not both. With neither, the module does nothing. The schema is checked while you build and when the server starts; [Validation](/guide/validation) explains what each check sees.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-safe-runtime-config'],
  safeRuntimeConfig: {
    $schema: runtimeConfigSchema,
  },
})
```

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| `$schema` | `StandardSchemaV1 \| string` | | A [Standard Schema](https://standardschema.dev/), or a path from the project root to a module that default-exports one. Use a path for [transforms and refinements](/guide/environment-overrides#transform-values-with-a-schema-module). |
| `envSchema` | `string \| { file: string, paths?: Record<string, string> }` | | Experimental. An annotated [`.env.example`](/guide/env-schema), with optional [nested paths](/guide/env-schema#nested-config). Checked only when the server starts. |
| `requireAtBuild` | `boolean` | `false` | Fail the build on an `undefined` or `''` value too, not only on a wrong one. For CI that builds with every production value. See [Validation](/guide/validation#require-every-value-at-build). |
| `validateAtBuild` | `boolean` | | Deprecated. See [the upgrade table](/guide/validation#upgrade-from-validateatbuild-and-validateatruntime). |
| `validateAtRuntime` | `boolean` | | Deprecated. The server start check always runs; `false` still turns it off for now. |
| `onError` | `'throw' \| 'warn' \| 'ignore'` | `'throw'` | What a failed check does. See [When a check fails](/guide/validation#when-a-check-fails). |
| `jsonSchemaTarget` | `'draft-2020-12' \| 'draft-07' \| 'openapi-3.0'` | `'draft-2020-12'` | The JSON Schema draft requested from your schema library for runtime checks, coercion and types. Change it only if your library can't produce the default. |

When a library has no JSON Schema output of its own, the module converts it with [@standard-community/standard-json](https://github.com/standard-community/standard-json). The converters for Valibot and Zod ship with the module, so you don't install them.

On Nuxt 5, `validateAtRuntime: false` or `onError: 'warn' | 'ignore'` keeps your `$schema` under the module's control instead of registering it for Nuxt's mandatory native checks. See [Nuxt 5 validation settings](/guide/nuxt-5#preserve-validation-settings).

## `useSafeRuntimeConfig()`

```ts
function useSafeRuntimeConfig(event?: { context: object }): SafeRuntimeConfig
```

Auto-imported in the app and in `server/`. For explicit imports, use `#imports` in app code and `#safe-runtime-config/server` in server code. Without an event it returns the current runtime config. With an H3 event it returns that request's config, the checked version of `useRuntimeConfig(event)`. The return type comes from `.nuxt/types/safe-runtime-config.d.ts`, described in [Types](/guide/type-safety).
