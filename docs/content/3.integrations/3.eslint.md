---
title: ESLint
description: Flag useRuntimeConfig() calls and replace them with useSafeRuntimeConfig().
navigation.icon: simple-icons:eslint
---

The `prefer-safe-runtime-config` rule reports every `useRuntimeConfig()` call. Its fix renames the call to `useSafeRuntimeConfig()` and keeps the arguments, so `useRuntimeConfig(event)` becomes `useSafeRuntimeConfig(event)`.

```ts
const config = useRuntimeConfig() // reported
const config = useSafeRuntimeConfig() // ok
```

## Setup

With [@nuxt/eslint](https://eslint.nuxt.com), the rule is registered at `warn` when the module has a schema. Nothing to configure.

Without it, add the recommended config:

```js [eslint.config.mjs]
import { configs } from 'nuxt-safe-runtime-config/eslint'

export default [
  configs.recommended,
]
```

Or register the plugin and pick the severity:

```js [eslint.config.mjs]
import safeRuntimeConfig from 'nuxt-safe-runtime-config/eslint'

export default [
  {
    plugins: { 'safe-runtime-config': safeRuntimeConfig },
    rules: { 'safe-runtime-config/prefer-safe-runtime-config': 'error' },
  },
]
```

## Migrate an app

Run the fix once to move every call site:

```bash
npx eslint --fix .
```

Then set the rule to `'error'` so new calls fail CI.
