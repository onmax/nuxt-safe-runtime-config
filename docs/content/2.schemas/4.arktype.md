[ArkType](https://arktype.io/) 2.x implements Standard Schema and writes types in TypeScript-like strings.

```bash
pnpm add arktype
```

```ts [nuxt.config.ts]
import { type } from 'arktype'

export default defineNuxtConfig({
  modules: ['nuxt-safe-runtime-config'],
  runtimeConfig: {
    databaseUrl: '',
    smtp: { host: '', port: 587 },
    public: { apiBase: 'https://api.example.com', logLevel: 'info' },
  },
  safeRuntimeConfig: {
    $schema: type({
      databaseUrl: 'string.url',
      smtp: {
        host: 'string > 0',
        port: '1 <= number.integer <= 65535',
      },
      public: {
        apiBase: 'string.url',
        logLevel: '\'debug\' | \'info\' | \'warn\' | \'error\'',
      },
    }),
  },
})
```

## Patterns

```ts
type({
  // required and optional
  'secret': 'string >= 32',
  'sentryDsn?': 'string.url',
  'timeout': 'number = 5000',

  // enums and lists
  'region': '\'eu\' | \'us\'',
  'allowedOrigins': 'string.url[]',

  // formats
  'adminEmail': 'string.email',
  'slug': /^[a-z-]+$/,
})
```

With `validateAtRuntime`, `number`, `boolean`, string unions and arrays accept the matching `NUXT_*` strings through [coercion](/guide/environment-overrides#coercion).

For morphs (`.pipe()`, `string.numeric.parse`) or `.narrow()`, move the schema into a [schema module](/guide/environment-overrides#transform-values-with-a-schema-module).
