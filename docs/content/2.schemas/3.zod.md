[Zod](https://zod.dev/) 3.24+ and 4 implement Standard Schema. The examples use Zod 4.

```bash
pnpm add zod
```

```ts [nuxt.config.ts]
import { z } from 'zod'

export default defineNuxtConfig({
  modules: ['nuxt-safe-runtime-config'],
  runtimeConfig: {
    databaseUrl: '',
    smtp: { host: '', port: 587 },
    public: { apiBase: 'https://api.example.com', logLevel: 'info' },
  },
  safeRuntimeConfig: {
    $schema: z.object({
      databaseUrl: z.url(),
      smtp: z.object({
        host: z.string().min(1),
        port: z.int().min(1).max(65535),
      }),
      public: z.object({
        apiBase: z.url(),
        logLevel: z.enum(['debug', 'info', 'warn', 'error']),
      }),
    }),
  },
})
```

## Patterns

```ts
z.object({
  // required and optional
  secret: z.string().min(32),
  sentryDsn: z.url().optional(),
  timeout: z.number().default(5000),

  // enums and lists
  region: z.enum(['eu', 'us']),
  allowedOrigins: z.array(z.url()),

  // formats
  adminEmail: z.email(),
  slug: z.string().regex(/^[a-z-]+$/),
})
```

With `validateAtRuntime`, `z.number()`, `z.boolean()`, `z.enum()` and `z.array()` accept the matching `NUXT_*` strings through [coercion](/guide/environment-overrides#coercion). `z.coerce` is not needed, and turns `'false'` into `true`.

For `.transform()`, `.refine()` or `.superRefine()`, move the schema into a [schema module](/guide/environment-overrides#transform-values-with-a-schema-module).
