[Valibot](https://valibot.dev/) 1.x implements Standard Schema natively.

```bash
pnpm add valibot
```

```ts [nuxt.config.ts]
import * as v from 'valibot'

export default defineNuxtConfig({
  modules: ['nuxt-safe-runtime-config'],
  runtimeConfig: {
    databaseUrl: '',
    smtp: { host: '', port: 587 },
    public: { apiBase: 'https://api.example.com', logLevel: 'info' },
  },
  safeRuntimeConfig: {
    $schema: v.object({
      databaseUrl: v.pipe(v.string(), v.url()),
      smtp: v.object({
        host: v.pipe(v.string(), v.minLength(1)),
        port: v.pipe(v.number(), v.integer(), v.minValue(1), v.maxValue(65535)),
      }),
      public: v.object({
        apiBase: v.pipe(v.string(), v.url()),
        logLevel: v.picklist(['debug', 'info', 'warn', 'error']),
      }),
    }),
  },
})
```

## Patterns

```ts
v.object({
  // required and optional
  secret: v.pipe(v.string(), v.minLength(32)),
  sentryDsn: v.optional(v.pipe(v.string(), v.url())),
  timeout: v.optional(v.number(), 5000),

  // enums and lists
  region: v.picklist(['eu', 'us']),
  allowedOrigins: v.array(v.pipe(v.string(), v.url())),

  // formats
  adminEmail: v.pipe(v.string(), v.email()),
  slug: v.pipe(v.string(), v.regex(/^[a-z-]+$/)),
})
```

With `validateAtRuntime`, `v.number()`, `v.boolean()`, `v.picklist()` and `v.array()` accept the matching `NUXT_*` strings through [coercion](/guide/environment-overrides#coercion). No `v.transform()` is needed for them.

For `v.transform()` or a `v.check()` across fields, move the schema into a [schema module](/guide/environment-overrides#transform-values-with-a-schema-module).
