Options go under `safeRuntimeConfig` in `nuxt.config.ts`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-safe-runtime-config'],
  safeRuntimeConfig: {
    $schema: runtimeConfigSchema,
    validateAtRuntime: true,
  },
})
```

## Schema

Set exactly one of `$schema` and `envSchema`. Without either, the module does nothing.

::field-group
  ::field{name="$schema" type="StandardSchemaV1 | string"}
  A [Standard Schema](https://standardschema.dev/) object, or a project-relative path to a module that default-exports one. An inline schema must convert to JSON Schema. Use a path when the schema has transforms; see [Environment overrides](/guide/environment-overrides#transform-values-with-a-schema-module).
  ::

  ::field{name="envSchema" type="string | { file: string, paths?: Record<string, string> }"}
  Experimental. Path to an annotated `.env.example`, or the path plus explicit config paths for nested keys. Turns on runtime validation. See [.env.example schemas](/guide/env-schema).
  ::
::

## Validation

::field-group
  ::field{name="validateAtBuild" type="boolean" default="!validateAtRuntime"}
  Validate the `nuxt.config.ts` values during `nuxt dev` and `nuxt build`.
  ::

  ::field{name="validateAtRuntime" type="boolean" default="false"}
  Coerce and validate the config when the server starts and for each request config. Always on with `envSchema`.
  ::

  ::field{name="onError" type="'throw' | 'warn' | 'ignore'" default="'throw'"}
  What a failure does. See [When validation fails](/guide/validation#when-validation-fails).
  ::

  ::field{name="jsonSchemaTarget" type="'draft-2020-12' | 'draft-07' | 'openapi-3.0'" default="'draft-2020-12'"}
  The JSON Schema draft requested from your schema library. It is used for inline runtime validation, for coercion and for generated types. Change it only if your library cannot produce the default.
  ::
::

Inline schemas without native JSON Schema output are converted with [@standard-community/standard-json](https://github.com/standard-community/standard-json). The Valibot and Zod converters ship with the module, so the app does not install them.
